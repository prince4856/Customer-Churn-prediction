# Customer Churn Prediction System

## Project Overview
The **Customer Churn Prediction System** is a Machine Learning project that predicts whether a customer is likely to leave a company's services. It analyzes customer information and usage patterns to identify customers who may churn.

The goal is to help businesses understand customer behavior, identify high-risk customers, and improve customer retention strategies.

## Problem Statement
Customer churn is a major challenge for businesses because losing existing customers can affect revenue and growth. This project uses Machine Learning classification algorithms to predict customer churn based on historical customer data.

## Dataset
- Dataset: Telco Customer Churn
- File: `WA_Fn-UseC_-Telco-Customer-Churn.csv`
- Contains customer demographics, services, account information, and churn status.
- Target Variable: `Churn`

## Machine Learning Algorithms
The following classification algorithms were implemented and compared:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- Gradient Boosting
- XGBoost

## Model Evaluation
Models were evaluated using classification performance metrics such as:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
